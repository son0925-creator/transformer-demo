
# Osmer's Four Dimensions of Faith: AI Analysis

## Overview
This project applies machine learning to analyze
four dimensions of Christian faith:

- Belief
- Relationship
- Commitment
- Mystery

## Methods
1. TF-IDF text vectorization
2. Perceptron classification
3. Multilayer Perceptron (MLP)
4. Cross-validation and confusion matrix
5. Comparative analysis of model performance

## Educational Purpose
Graduate-level religious education and AI literacy.

## Data
Synthetic training data are used for demonstration.
Student reflection data are not publicly shared.

## Limitations
The models classify linguistic expressions of faith,
not personal faith or spiritual maturity.
